# Sales & Revenue Analysis Dashboard

## Project Overview
An interactive Sales & Revenue Analysis Dashboard developed using Microsoft Power BI to analyze business performance and identify important sales trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Performance Indicators
- Total Revenue
- Total Profit
- Total Orders
- Total Quantity
- Average Order Value

## Dashboard Features
- Monthly Revenue Trend
- Revenue by Product Category
- Revenue by Region
- Top 5 Products by Revenue
- Category Filter
- Payment Mode Filter

## Key Business Insights
- Total Revenue: 6.53M
- Total Profit: 1.15M
- Total Orders: 236
- Electronics is the highest-revenue category.
- South is the highest-revenue region.
- Laptop is the leading product among the displayed top five.
